# Women Empowering Job Portal

## 📌 Project Overview

Women Empowering Job Portal is a frontend web project designed to help women discover and explore job opportunities through a simple and user-friendly interface.

## 🎯 Project Purpose

The purpose of this project is to create a user-friendly job portal that helps women discover and explore suitable job opportunities. The platform provides a simple and accessible interface for browsing job opportunities and aims to support women in finding employment opportunities and building their careers.

## 🚀 Features

- User-friendly interface
- Job opportunity exploration
- Women-focused job portal
- Login page
- Responsive design
- Simple and clean UI

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Vite
- Git & GitHub

## 📂 Project Structure

- `index.html` – Main webpage
- `login.html` – Login page
- `style.css` – Styling
- `script.js` – JavaScript functionality
- `main.js` – Main JavaScript file
- `package.json` – Project dependencies and configuration
